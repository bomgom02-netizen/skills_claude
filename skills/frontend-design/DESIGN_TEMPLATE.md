## Ready to Build

If you can answer all critique questions with confidence, move to **Pass 2: Build & Refine**.

**Build Checklist:**
- [ ] Design tokens entered in code (colors, spacing, typography)
- [ ] Components built to spec
- [ ] Full page/flow assembled
- [ ] Responsive breakpoints tested
- [ ] Interactions polished (transitions, hover, focus states)
- [ ] Accessibility verified (WCAG AA)
- [ ] Final self-critique complete
- [ ] Ready to ship

---

## Questions While Building?

If something doesn't feel right during build:

1. **Is it the plan?** Go back to this doc and adjust
2. **Is it the implementation?** Fix the code/design
3. **Is it both?** Kill it and rethink

Remember: Intentionality beats perfection. Ship something you can explain.

---

**Design is done when you can point to every choice and say: "I did this because..."**
